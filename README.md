Campus

Campus — вебзастосунок для розміщення та пошуку оголошень, орієнтований на студентів.

Проблема та мета

Campus спрощує пошук і розміщення оголошень серед студентів та дозволяє зібрати пропозиції товарів і послуг в одному місці.

Мета проєкту — створити зручний вебзастосунок для публікації, пошуку та перегляду оголошень.

Цільова аудиторія

Студенти, які бажають купувати, продавати або обмінювати товари, а також знаходити чи пропонувати послуги.

Ролі користувачів

- Гість
- Користувач
- Модератор
- Адміністратор

Основні функції

- реєстрація та авторизація;
- перегляд каталогу оголошень;
- пошук та фільтрація оголошень;
- створення та редагування оголошень;
- керування профілем;
- додавання оголошень до обраного;
- модерація оголошень;
- керування користувачами та категоріями.
