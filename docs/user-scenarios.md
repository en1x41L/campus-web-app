# Сценарії користувачів Campus

## Сценарій 1 — Гість

**Мета:** знайти потрібне оголошення.

**Початкові умови:** користувач відкрив Campus без авторизації.

**Дії користувача:**
1. Відкриває каталог оголошень.
2. Вводить назву в пошуку або обирає категорію.
3. Відкриває потрібне оголошення.

**Реакція системи:** система показує оголошення, які відповідають запиту.

**Результат:** потрібне оголошення знайдено.

**Помилка / альтернативний шлях:** якщо оголошень немає, система показує повідомлення про відсутність результатів.


## Сценарій 2 — Користувач

**Мета:** створити нове оголошення.

**Початкові умови:** користувач авторизований у системі.

**Дії користувача:**
1. Відкриває форму створення оголошення.
2. Вводить назву, опис і ціну.
3. Обирає категорію.
4. Додає фото.
5. Зберігає оголошення.

**Реакція системи:** система перевіряє введені дані та створює оголошення.

**Результат:** нове оголошення створено.

**Помилка / альтернативний шлях:** якщо обов’язкові поля не заповнені, система повідомляє про помилку.


## Сценарій 3 — Модератор

**Мета:** перевірити оголошення.

**Початкові умови:** модератор авторизований та має відповідні права.

**Дії користувача:**
1. Відкриває список оголошень.
2. Переглядає оголошення.
3. Приймає рішення щодо оголошення.

**Реакція системи:** система зберігає рішення модератора та змінює статус оголошення.

**Результат:** оголошення перевірено.

**Помилка / альтернативний шлях:** модератор може залишити оголошення або приховати його у разі порушення правил.


## Сценарій 4 — Адміністратор

**Мета:** змінити роль користувача.

**Початкові умови:** адміністратор авторизований у системі.

**Дії користувача:**
1. Відкриває список користувачів.
2. Обирає потрібного користувача.
3. Змінює його роль.
4. Зберігає зміни.

**Реакція системи:** система перевіряє права адміністратора та зберігає зміни.

**Результат:** роль користувача змінено.

**Помилка / альтернативний шлях:** якщо зміни неможливо зберегти, система повідомляє про помилку.
